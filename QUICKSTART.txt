================================================================================
IMMEDIATE STEPS
================================================================================

1. OPEN IN UNITY
   - Open Unity Hub
   - Click "Add" → Select this project folder
   - Open with Unity 6000.3.2f1+

2. ASSIGN PREFABS (CRITICAL!)
   
   GridManager (in Hierarchy):
   - Shelf Prefab   → Assets/Prefabs/Shelves/ShelfPrefab
   - Fridge Prefab  → Assets/Prefabs/Shelves/FridgePrefab  
   - Checkout Prefab → Assets/Prefabs/Checkout/CheckoutPrefab
   
   CustomerSpawner (in Hierarchy):
   - Customer Prefab → Assets/Prefabs/Customer/CustomerPrefab

3. TEST IN PLAY MODE
   - Press Play button
   - Customers spawn every 5 seconds
   - Press 'B' to build, WASD to move camera

================================================================================
CONTROLS
================================================================================

B              - Open Build Menu
S              - Open Shop Menu
ESC            - Close Menus
WASD / Arrows  - Pan Camera
Mouse Scroll   - Zoom Camera
Middle Mouse   - Drag Pan
Left Click     - Place Object / Interact
Right Click    - Cancel Placement

================================================================================
WEBGL BUILD
================================================================================

1. File → Build Settings
2. Select WebGL platform
3. Click "Switch Platform" (wait for processing)
4. Click "Build" → Choose output folder
5. Serve via HTTP server (NOT file://)
   
   Python:  python -m http.server 8000
   Node:    npx http-server

================================================================================
GAME FLOW
================================================================================

1. Start with $5,000
2. Press 'B' to open build menu
3. Place shelves ($100), fridges ($200), checkouts ($150)
4. Customers spawn automatically (every 5 seconds, max 10)
5. Customers shop → pick products → go to checkout
6. Money increases when customers complete purchases
7. Expand and grow your supermarket!

================================================================================
TROUBLESHOOTING
================================================================================

No customers spawning?
→ Assign CustomerPrefab in CustomerSpawner (Hierarchy)

Can't place objects?
→ Assign prefabs in GridManager (Hierarchy)
→ Ensure you have enough money
→ Press 'B' to open build menu first

Grid not visible?
→ Select GridManager → Enable "Show Grid" in Inspector

WebGL build fails?
→ Install WebGL Build Support in Unity Hub
